# ✈️ Wanderly — Travel Website UI Design

Wanderly is a modern and visually appealing travel website UI design created in Figma. The design focuses on beautiful destinations, travel inspiration, and a clean, user-friendly interface.

The goal is to provide users with an engaging visual experience while exploring travel destinations around the world.

## 🎨 Design Tool

- **Tool:** Figma
- **Project Type:** Travel Website UI/UX Design
- **Design Style:** Modern, Minimal, Premium
- **Category:** Travel & Tourism

## ✨ Design Features

- **Hero Section:** Attractive travel background with a headline and call-to-action button.
- **Navigation Bar:** Simple and clean navigation menu.
- **Destination Cards:** Beautiful destination cards featuring places such as Bali, Swiss Alps, Kyoto, Amalfi Coast, and Rajasthan.
- **Travel Search Section:** UI for selecting destinations, travel styles, and trip duration.
- **Travel Experiences:** Sections highlighting adventure, relaxation, and cultural experiences.
- **Newsletter Section:** Email subscription interface.
- **Footer:** Organized navigation links and brand information.

## 🎨 Design Theme

The design uses a nature-inspired color palette to create a relaxing and premium travel experience.

- **Primary Color:** Forest Green
- **Secondary Color:** Cream
- **Accent Color:** Lime Green
- **Typography:** Modern sans-serif and elegant serif fonts
- **Visual Elements:** Travel photography, destination cards, buttons, and minimal icons


## 🛠️ Figma Design Process

1. Created the main website layout.
2. Designed the navigation bar and hero section.
3. Added destination cards and travel experience sections.
4. Selected suitable typography and colors.
5. Organized the UI elements for a consistent design.
6. Refined spacing, alignment, and visual hierarchy.

## 📱 Responsive Design

The design concept considers different screen sizes, including desktop, tablet, and mobile layouts.
